# MyFramework Tower Defense Demo

基于 [MyFramework](https://github.com/ZHOURUIH/MyFramework) 开发的 Rogue-like 塔防游戏实战 Demo。

用于展示 MyFramework 在一个完整 Unity 项目中的工程结构、开发流程和实际使用方式。

[MyFramework 主仓库](https://github.com/ZHOURUIH/MyFramework) · [问题反馈](https://github.com/ZHOURUIH/MyFramework_TDDemo/issues)

## 项目介绍

MyFramework Tower Defense Demo 是一个基于 MyFramework 开发的完整塔防游戏示例。

该项目不是单个功能的代码片段，而是一个包含项目启动、场景流程、配置表、战斗逻辑、角色管理、UI、音效、特效和热更新结构的完整 Unity 工程。

通过本项目可以了解 MyFramework 各个系统在实际游戏业务中的组织方式，以及框架层和游戏业务层之间的协作方式。

## 框架能力展示

本项目主要展示了 MyFramework 以下功能在实际游戏项目中的使用方式。

### 工程代码分层

项目代码按照以下目录进行组织：

* `Game`：非热更新游戏代码
* `HotFix`：热更新业务代码
* `AutoGenerated`：自动生成代码
* `Editor`：Unity 编辑器工具

这种结构将启动层、框架接入层、热更新业务层和自动生成代码分离，方便项目持续开发和维护。

### 场景流程管理

Demo 使用场景流程管理游戏启动、加载、登录、主界面和战斗流程，包括：

* 游戏启动
* 资源初始化
* 场景加载
* 大厅流程
* 战斗流程
* 关卡结束
* 返回大厅

### 塔防战斗系统

塔防战斗部分包含：

* 战斗模式管理
* Rogue-like 战斗规则
* 怪物波次生成
* 怪物路线管理
* 炮塔管理
* 子弹管理
* 战斗状态管理
* 金币、经验和生命值管理
* 胜负条件判断

### 配置表系统

项目中的关卡、怪物、炮塔、技能、波次、音效和多语言等数据均通过配置表管理。

主要配置包括：

* `Level`：关卡配置
* `WaveConfig`：怪物波次配置
* `Monster`：怪物配置
* `MonsterSkill`：怪物技能配置
* `Tower`：炮塔配置
* `TowerSkill`：炮塔技能配置
* `TowerTalent`：炮塔天赋配置
* `SkillBullet`：技能子弹配置
* `BulletDamageModifier`：子弹伤害修正配置
* `CardPoolConfig`：随机卡池配置
* `RewardConfig`：奖励配置
* `Audio`：音效配置
* `Effect`：特效配置
* `Localization`：多语言配置
* `GlobalConfig`：全局配置

配置表原始文件和相关工具位于：

```text
Excels/
```

推荐使用以下环境打开项目：

```text
Unity 2022.3.62f2c1
```

项目主要使用：

* Unity
* C#
* Universal Render Pipeline
* MyFramework

* Obfuz

建议使用项目指定的 Unity 版本，避免因 Unity、URP 或 Package 版本差异产生兼容性问题。

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/ZHOURUIH/MyFramework_TDDemo.git
```

### 2. 使用 Unity Hub 打开项目

在 Unity Hub 中选择：

```text
Add project from disk
```

然后选择项目根目录。

### 3. 等待依赖加载

首次打开项目时，Unity Package Manager 会自动下载 MyFramework、HybridCLR、Obfuz 等依赖。

请等待 Unity 完成以下工作：

* Package 下载
* 脚本编译
* 资源导入
* Shader 编译

首次打开所需时间可能较长。

### 4. 打开启动场景

启动场景路径：

```text
Assets/Resources/Scene/start.unity
```

### 5. 运行游戏

打开启动场景后，点击 Unity 编辑器顶部的 Play 按钮即可运行。

## 核心代码

### 塔防系统

塔防战斗的核心代码位于：

```text
Assets/Scripts/HotFix/TowerDefenceSystem/
```

其中主要包含：

```text
TowerDefenceSystem.cs
BattleModeBase.cs
BattleModeRogue.cs
MonsterGenerator.cs
MonsterRoad.cs
```

### TowerDefenceSystem

负责管理塔防战斗的整体状态和数据，包括：

* 当前战斗场景
* 当前战斗模式
* 战斗角色
* 当前波次
* 玩家生命值
* 金币
* 经验
* 战斗状态
* 胜负判断

### BattleModeRogue

负责 Rogue-like 模式下的战斗规则，包括：

* 可使用炮塔
* 炮塔天赋
* 随机卡池
* 金币消耗
* 炮塔放置
* 炮塔出售
* 波次结束处理

### MonsterGenerator

负责根据波次配置生成怪物，包括：

* 波次开始
* 怪物生成数量
* 怪物生成间隔
* 不同怪物类型
* 波次结束判断

### MonsterRoad

负责管理怪物移动路线，包括：

* 地面怪物路线
* 飞行怪物路线
* 路线节点
* 怪物出生点
* 怪物终点

## 常见问题

### 首次打开项目出现大量编译错误

首次打开时，Package Manager 可能仍在下载依赖。

请先等待 Unity 完成 Package 下载和脚本编译。如果依赖下载失败，请检查网络环境以及 `Packages/manifest.json` 中的 Git 依赖是否可以正常访问。

### 找不到启动场景

启动场景路径为：

```text
Assets/Resources/Scene/start.unity
```

请不要直接从战斗场景开始运行，否则部分框架系统可能没有完成初始化。

### Unity 版本不一致

推荐使用：

```text
Unity 2022.3.62f2c1
```

其他 Unity 版本可能会出现 Package、URP、序列化数据或脚本 API 不兼容的问题。

### README 中的视频无法播放

建议确认：

* 视频格式为 MP4
* 视频使用 H.264 编码
* 视频地址单独占据一行
* 地址为 GitHub 生成的 `user-attachments` 地址
* 视频文件没有超过 GitHub 的附件大小限制
